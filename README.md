Sales Analysis Dashboard – Power BI

1. Project Overview

This project presents an interactive sales analysis dashboard created in Microsoft Power BI.

The goal is to analyze sales performance, profitability and customer demographics.

2. Business Questions

- Which country generates the highest profit?
- Which age group is the most profitable?
- How are sales distributed by gender?
- Which customer segments generate the highest revenue?

3. Key Metrics

- Total Sales
- Total Profit
- Sales by Gender
- Profit by Age Group
- Most Profitable Country

4. Tools & Technologies

- Microsoft Power BI
- DAX
- Data Visualization
- Data Analysis

5. Skills Demonstrated

- Data analysis
- Creating DAX measures
- Building interactive dashboards
- Business reporting
- Drawing business insights

6. Project Goal

To transform sales data into meaningful business insights and support data-driven decision-making.
